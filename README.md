# 🌐 Abdul Sabor Rasooli — Personal Portfolio Website

A bilingual (Persian / English) personal portfolio website built from scratch with plain HTML, CSS, and JavaScript. It introduces me, my skills, and my projects, with a smooth language switcher between Farsi (RTL) and English (LTR).

🔗 **Live Demo:** (https://saborrasoolipy.github.io/saborrasooli/)

---

## ✨ Features 

- 🌍 **Bilingual support** — instantly switch between Persian (فارسی) and English, with automatic RTL/LTR layout switching
- 🎨 **Clean, modern design** — custom color palette, elegant typography (Vazirmatn for Farsi, Fraunces/Inter for English)
- 📱 **Fully responsive** — adapts smoothly from mobile to desktop
- ⚡ **No frameworks** — built with vanilla HTML, CSS, and JavaScript only
- 🧩 **Dynamic content rendering** — skills and projects are rendered from a JSON-like i18n object, making the site easy to update or extend
- ♿ **Accessibility-minded** — respects `prefers-reduced-motion`, visible focus states

## 📂 Sections

| Section | Description |
|---|---|
| **Hero** | Introduction and quick call-to-action buttons |
| **About** | Short background about my education and interests |
| **Skills** | Tags showing my current technical skills |
| **Projects** | Cards showcasing my personal projects |
| **Experience** | Timeline of my work experience |
| **Contact** | Email and GitHub links |

## 🛠️ Tech Stack

- HTML5
- CSS3 (custom properties / variables)
- Vanilla JavaScript (i18n logic, dynamic DOM rendering)
- [Google Fonts](https://fonts.google.com/) — Vazirmatn, Fraunces, Inter

## 🚀 Getting Started

Since this is a static site with no build step, you can run it locally with just a browser:

```bash
git clone https://github.com/saborrasooliPy/YOUR-REPO-NAME.git
cd YOUR-REPO-NAME
```

Then simply open `index.html` in your browser, or serve it locally:

```bash
# Using Python
python3 -m http.server 8000
```

Visit `http://localhost:8000` in your browser.
